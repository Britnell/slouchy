# Development Rules
- in your replies, always be as brief as possible. rather be too brief, follow up questions can always be asked
- I cannot read an essay in every response, when i need more detail i will ask for it
- don't give a long explanation or background context without being asked for it
- answer the question directly, don't write an essay on the topic
- don't repeat or explain what has already been established
- when info is needed it will be asked for
- be minimal in reading files. don't read more than you need to know to complete the task. 
- you do not need "more context" to complete the task, generally you will be given context/reference for the task at hand. 
- if you need more information, the task is unclear, then ask a question. i'd prefer too many questions than too few 
- i have dev server running - ask me for debug output or errors
